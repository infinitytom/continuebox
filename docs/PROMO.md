《葬送的芙莉莲》弹幕段来自用户新增的实际录屏，截取原始视频 00:12–00:30。保留发送弹幕对话框、发送操作、客户端“已发送到续映服务器弹幕库”的提示，以及随播放变化的弹幕。没有用静态图模拟滚动弹幕，也没有额外生成弹幕覆盖层。录屏显示发送成功提示，尚未另行验证另一客户端接收到这条新发送的弹幕。

相关推荐段使用已配置 TMDB 的自部署同步服务，在《幸福终点站》详情页实际加载推荐卡片；点击《喜剧之王》后展示全局搜索结果。订阅配置、站点与分类来自饭太硬订阅实际返回。上述自行录制的片段使用完整未修改的 Release APK；用户提供的应用宝和安卓录屏安装版本未独立核验。

此剪辑已移除先前的原创测试片《山海之间》、虚构演示片库、演示账号登录/设备管理画面，以及静态弹幕截图。接续和账号功能在介绍页说明，当前视频没有重演跨设备接续流程；主页连接状态不代表重新完成了第三方授权和同步测试。

## 订阅与使用条件

点播订阅地址：`http://www.饭太硬.cc/tv`。[饭太硬资源导航](https://www.xn--sss604efuw.cc/) · [配置教程](SUBSCRIPTIONS.md)。导航和兼容的订阅地址同样可用于普通 TVBox，并非续映专属资源。APK 不预装订阅，具体线路取决于片源、插件和网络环境。

弹幕发送需登录自己的续映同步服务；接收需启用相应弹幕来源。相关推荐需要服务端配置 TMDB Read Access Token。Emby、NeoDB、Trakt 需要配置对应服务和账号。

## 检查与已有问题

用户录屏原声音轨已移除，成片只有原创合成器纯音乐，无歌词、无人声或第三方采样，末尾淡出。已通过完整解码、分辨率、时长及单音轨检查，摘要见 [video-validation.json](validation/video-validation.json)。

本次仅更新视频与文档，没有修改 APK。此前 Android Studio 模拟器测试的部分片源曾触发 ARM 转译兼容错误；更早的跨设备测试在连续返回后曾出现播放信息错误和进度归零，仍需排查。用户真实录屏展示了对应环境中的实际播放与弹幕操作，不代表所有线路和设备均已验证。
