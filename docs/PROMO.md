## 录制方式

全部产品画面来自 Android `screenrecord`。使用本次 Release 的完整 `ContinueBox-2.2.5.apk`，通过 Android 11 Google APIs 模拟器自带的 ARM 转译运行，实际主 ABI 为 arm64-v8a；没有替换 APK 中的资源或代码，也没有移除原生库。

片名、海报、分类、更新集数和详情来自用户指定订阅实际返回的数据；这版已替换原宣传片中的虚构演示片单。APK 不预装此订阅，不提供或托管这些资源。录制环境没有录入私人 NAS、真实账号、令牌、SMTP 或网盘资料。

剪辑包含字幕、片头片尾与手机画面排版；静止画面按实际停留时间补齐，未改写界面中的状态和结果。具体影片和更新信息仅代表录制时第三方站点的响应。

## 已验证范围

订阅导入、站点切换、分类片库、海报、资源详情、选集列表、收藏和横竖屏浏览均已实际操作。当前安卓转译环境试播时触发原生兼容错误，未完成资源播放验证；视频关闭窗口预览，展示资源浏览和详情，不宣称所有播放线路可用。ARM 真机的播放效果仍需在具体设备验证。

## 音乐

BGM 是本次用合成器波形原创编排的无歌词纯音乐，约 96 BPM，包括和弦铺底、拨弦与轻节奏，无第三方音频采样，无语音合成。视频的唯一音轨来自该音乐，响度目标 -18 LUFS，并做淡入淡出。视频已通过完整解码检查。
