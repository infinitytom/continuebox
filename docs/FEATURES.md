# 续映增加了什么

续映保留 TVBox 的订阅、选集和多播放器能力，重点扩展“这次看到哪里，下次从哪里继续”。下表以本项目所基于的 TVBoxOS 工作流为参照；其他 TVBox 分支可能也有类似扩展，不代表所有分支的功能对比。

| 场景 | TVBox 基础播放工作流 | 续映的扩展 |
|---|---|---|
| 换一台电视或手机 | 在当前设备打开资源、播放 | 同一同步账号恢复历史、分集与观看位置；暂停和退出时提交进度 |
| 换一个数据源 | 重新搜索、进入对应站点详情 | 使用片名、年份与集号匹配跨源观看进度；明确年份不同的同名内容不会合并 |
| 多人使用 | 使用当前设备保存的数据 | 多服务器、多账号登录记录；切换账号后使用对应账号的同步数据 |
| 管理登录 | 本机应用设置 | 查看登录设备，解除单台设备或退出全部设备；支持邮箱验证和账号管理 |
| 发现下一部作品 | 查看当前片源详情 | TMDB 相关推荐与演职员资料；点击推荐片名发起全局搜索 |
| 弹幕 | 使用片源或已配置的弹幕接口 | 聚合公共库、续映库、额外接口与片源弹幕，并提供来源优先级设置 |
| 自有媒体库和观影记录 | 配置对应数据源 | Emby 直连及进度联动、Trakt 与 NeoDB 授权入口；需要自行配置对应服务 |

## 最短体验路径

1. 安装[公开版 APK](https://github.com/infinitytom/continuebox/releases/tag/v2.2.5)，配置[订阅](SUBSCRIPTIONS.md)或自己的 Emby。
2. 部署仓库内的同步服务，在首页“连接与同步”登录自己的账号。
3. 在设备 A 播放并暂停，等待同步状态显示已连接、待上传为 0。
4. 在设备 B 登录同一服务和账号，打开历史记录，再进入对应影片接续观看。

跨源续播需要两边的片名、年份和集号能够可靠匹配；不同剪辑版本的时间轴也可能不同。网络失败时保留待上传状态并自动重试，具体同步状态可在“播放同步”查看。

相关推荐需要同步服务端配置 `TMDB_READ_TOKEN`（TMDB Read Access Token），客户端登录该同步服务，且服务能访问 TMDB。详情页向下浏览可查看相关推荐和演职员；推荐按片名搜索，因此搜索结果可能包含同名作品，仍需核对年份与版本。

弹幕聚合需要启用弹幕并配置可访问的来源。Emby、Trakt、NeoDB 的账号和服务由使用者配置，宣传片中没有实际绑定的服务仅介绍入口，不展示为已授权成功。
